# Design sources

These are snapshots of the chosen boards from the Claude Design canvas <https://claude.ai/artifact/DXzWX7bnxWX3i2zJCy1A8J>, which is private to the user. They are Design Component (`.dc.html`) sources. They need the canvas runtime to render, so read them as the exact source of measurements, colors and copy. [UX.md](../UX.md) is the spec; these back it up.

| File | Board | Use it for |
|---|---|---|
| `A-source-list.dc.html` | A · Source list | Window anatomy: rail, toolbar capsules, tiling panes with headers, inspector with Files/Changes, pane and editor visuals. Its rail is superseded by S2. |
| `S2-rail-slimmer.dc.html` | S2 · Slimmer | **The** rail: row heights, indents, fonts, dots and words, branch inline, servers as ordinary rows with a server icon and a port label |
| `attention-and-status.dc.html` | Attention and status | State words and colors across the rail, workspace rows, dock badge, notifications and pane headers |

The explored and rejected alternatives (B · Workspace strip, C · Floating glass, A1–A6, S1) exist only on the canvas.
